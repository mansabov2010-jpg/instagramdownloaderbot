# Render’da joylashtirish (Deploy)

Render ushbu repozitoriyaning Docker sozlamalari bilan eng yaxshi ishlaydi.

## Qadamlar

1. GitHub’da repozitoriyani fork qiling.
2. Fork qilingan repozitoriyangiz asosida yangi Render **Web Service** yarating.
3. Muhit (`environment`) sozlamasini **Docker** holatida qoldiring.
4. Birinchi muvaffaqiyatli deploy oldidan kerakli muhit o‘zgaruvchilarini (`environment variables`) qo‘shing.
5. Servisni repozitoriyaning asosiy katalogidan (root) joylashtiring.
