# Xavfsizlik siyosati (Security Policy)

## Qo‘llab-quvvatlanadigan versiyalar

Ushbu bo‘lim loyihaning qaysi versiyalariga hozirda xavfsizlik yangilanishlari taqdim etilayotganini ko‘rsatadi.

| Versiya | Qo‘llab-quvvatlanadi |
| ------- | ------------------- |
| 5.1.x   | :white_check_mark:  |
| 5.0.x   | :x:                 |
| 4.0.x   | :white_check_mark:  |
| < 4.0   | :x:                 |

## Zaiflik haqida xabar berish

Ushbu bo‘limda topilgan zaiflik haqida qanday xabar berish mumkinligi ko‘rsatiladi.

Xavfsizlik zaifligi aniqlanganda qayerga murojaat qilish kerakligi, xabar qilingan zaiflik bo‘yicha yangilanishlar qanchalik tez-tez berilishi, zaiflik qabul qilingan yoki rad etilgan taqdirda nimalarni kutish mumkinligi va boshqa tafsilotlarni bayon eting.
