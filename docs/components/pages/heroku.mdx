# Heroku’da joylashtirish (Deploy)

Heroku endi ushbu repozitoriya uchun asosiy (birinchi darajali) joylashtirish platformasi hisoblanmaydi.

## Sababi

Loyiha endi quyidagilarga tayangan holda ishlaydi:

- ildiz katalog (root)ga asoslangan ishga tushirish tuzilmasi
- bog‘liqliklarni (`dependencies`) boshqarish uchun `uv`
- birinchi o‘rinda Docker orqali joylashtirish yondashuvi

Eski Heroku’ga moslashtirilgan ishga tushirish fayllari repozitoriyadan olib tashlangan.

## Tavsiya

Agar eng sodda xosting yo‘lini tanlamoqchi bo‘lsangiz, buning o‘rniga joriy qo‘llanmadagi Railway yoki Render’dan foydalaning.
