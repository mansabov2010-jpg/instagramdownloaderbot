# Koyeb’da joylashtirish (Deploy)

Koyeb hali ham botni ishga tushira oladi, biroq qadamlar joriy Docker asosidagi ishga tushirish tizimiga qayta yozilmaguncha bu sahifa eski (legacy) ko‘rsatma hisoblanadi.

## Joriy talablar

Repozitoriyaning asosiy katalogidan (root) joylashtiring va asosiy deploy sahifasida ko‘rsatilgan muhit o‘zgaruvchilarini (`environment variables`) kiriting.

## Tavsiya etilgan muqobil

Agar bugungi kunda ko‘proq dolzarb va aniq ko‘rsatmali yo‘lni tanlamoqchi bo‘lsangiz, Railway yoki Render’dan foydalaning.
