# All Url Uploader hujjatlari (Docs)

Ushbu papka loyiha uchun tashqi hujjatlar (`documentation`) veb-saytini o‘z ichiga oladi.

Botning ishlashi `docs/` papkasiga bog‘liq emas, shuning uchun hujjatlar ilovasiga tegmasdan repozitoriyaning asosiy katalogidan (`root`) to‘g‘ridan-to‘g‘ri Telegram bot ustida ishlashingiz mumkin.
